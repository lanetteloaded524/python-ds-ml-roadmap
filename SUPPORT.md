# Support

Looking for help? Here's how to get it.

## 📖 Check Existing Resources First

1. **[TROUBLESHOOTING.md](TROUBLESHOOTING.md)** — Solutions to common setup and runtime issues
2. **[ROADMAP.md](ROADMAP.md)** — Full learning roadmap with curated resources
3. **[Documentation Site](https://djordjeperovic.github.io/python-ds-ml-roadmap/)** — Browse tutorials and cheat sheets online
4. **[Existing Issues](https://github.com/djordjeperovic/python-ds-ml-roadmap/issues)** — Search for your question — someone may have asked it already

## 💬 Ask a Question

If you couldn't find an answer in the resources above:

- **Open a [Question Issue](https://github.com/djordjeperovic/python-ds-ml-roadmap/issues/new?template=question.yml)** — Use the question template for learning-related or setup questions.

Please include:
- Which notebook or project you're working on
- What you tried and what went wrong
- Your Python version and OS

## 🐛 Report a Bug

Found something broken? **[Open a bug report](https://github.com/djordjeperovic/python-ds-ml-roadmap/issues/new?template=bug_report.yml)**.

## 💡 Suggest an Improvement

Have an idea to make this roadmap better? **[Open a feature request](https://github.com/djordjeperovic/python-ds-ml-roadmap/issues/new?template=feature_request.yml)**.
