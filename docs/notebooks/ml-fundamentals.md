# 🤖 ML Fundamentals

Build, evaluate, and compare classical machine learning models using scikit-learn. This notebook covers the full modeling lifecycle — from data preprocessing and model training to evaluation and hyperparameter tuning.

[![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/djordjeperovic/python-ds-ml-roadmap/blob/main/projects/02_ml_fundamentals/ml_fundamentals.ipynb)
[![View on GitHub](https://img.shields.io/badge/View-GitHub-blue?logo=github)](https://github.com/djordjeperovic/python-ds-ml-roadmap/blob/main/projects/02_ml_fundamentals/ml_fundamentals.ipynb)

## Topics Covered

- Linear regression and logistic regression
- Decision trees and random forests
- Support vector machines (SVMs)
- K-Means clustering and dimensionality reduction (PCA)
- Train/test splitting and cross-validation
- Hyperparameter tuning with GridSearchCV
- Evaluation metrics (accuracy, precision, recall, F1, AUC-ROC, confusion matrix)

## Prerequisites

- Completion of the Data Fundamentals and EDA notebooks
- Basic understanding of statistics (distributions, correlation)

## Key Takeaways

- Understand the difference between supervised and unsupervised learning
- Train, evaluate, and compare multiple ML algorithms on real data
- Use cross-validation to get robust performance estimates
- Tune hyperparameters systematically with grid search
- Choose appropriate evaluation metrics for different problem types
