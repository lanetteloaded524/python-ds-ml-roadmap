# 🔍 EDA Case Study

Practice real-world exploratory data analysis on a deliberately messy dataset. Learn the detective mindset of data cleaning and insight discovery, progressing from data quality assessment to feature engineering.

[![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/djordjeperovic/python-ds-ml-roadmap/blob/main/projects/01b_eda_case_study/eda_case_study.ipynb)
[![View on GitHub](https://img.shields.io/badge/View-GitHub-blue?logo=github)](https://github.com/djordjeperovic/python-ds-ml-roadmap/blob/main/projects/01b_eda_case_study/eda_case_study.ipynb)

## Topics Covered

- Data quality assessment: missing values, outliers, duplicates, inconsistent categories
- Univariate analysis (distributions, value counts)
- Bivariate analysis (correlations, group comparisons)
- Publication-quality visualizations for EDA
- Feature engineering from raw data to ML-ready features
- Data storytelling and insight communication

## Prerequisites

- Completion of the Data Fundamentals notebook
- Familiarity with Pandas and Matplotlib/Seaborn

## Key Takeaways

- Develop a systematic approach to exploring and cleaning messy datasets
- Identify and handle common data quality issues (missing data, outliers, duplicates)
- Create compelling visualizations that reveal patterns in data
- Engineer meaningful features that improve downstream ML models
- Communicate findings clearly through data storytelling
