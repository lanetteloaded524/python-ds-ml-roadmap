# 📐 Math & Statistics for ML

Build the mathematical foundation every ML practitioner needs. This notebook covers descriptive statistics, probability distributions, hypothesis testing, Bayes' theorem, and linear algebra essentials — all with intuitive explanations and visual demonstrations using Python.

## Topics Covered

- Descriptive statistics (mean, median, variance, standard deviation)
- Probability distributions (Normal, Binomial, Poisson)
- Central Limit Theorem
- Hypothesis testing (t-test, chi-square) and p-values
- Correlation and covariance
- Bayes' theorem and its connection to Naive Bayes
- Linear algebra essentials (vectors, matrices, dot product, eigenvalues)

## Prerequisites

- Basic Python knowledge (variables, loops, functions)
- Familiarity with basic math concepts (algebra, basic probability)

## Key Takeaways

- Understand how probability distributions underpin many ML algorithms
- Know when and how to apply hypothesis tests to validate assumptions
- Use Bayes' theorem to reason about conditional probabilities
- Perform core linear algebra operations that power ML models (PCA, SVMs, neural networks)
- Build visual intuition for abstract mathematical concepts
