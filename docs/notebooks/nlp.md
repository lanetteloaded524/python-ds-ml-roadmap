# 💬 NLP Fundamentals

Explore Natural Language Processing from text preprocessing to sentiment analysis. This notebook teaches you how to transform raw text into features for machine learning, covering the essential NLP pipeline.

[![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/djordjeperovic/python-ds-ml-roadmap/blob/main/projects/05_nlp/nlp_fundamentals.ipynb)
[![View on GitHub](https://img.shields.io/badge/View-GitHub-blue?logo=github)](https://github.com/djordjeperovic/python-ds-ml-roadmap/blob/main/projects/05_nlp/nlp_fundamentals.ipynb)

## Topics Covered

- Tokenization and text cleaning
- Stopword removal
- Stemming and lemmatization
- Bag-of-Words representation
- TF-IDF (Term Frequency-Inverse Document Frequency) vectorization
- Building text classification pipelines
- Sentiment analysis on real-world datasets

## Prerequisites

- Completion of the ML Fundamentals notebook
- Basic understanding of classification models
- Familiarity with scikit-learn's Pipeline and vectorizers

## Key Takeaways

- Build a complete NLP preprocessing pipeline from raw text to features
- Understand the difference between Bag-of-Words and TF-IDF representations
- Train and evaluate text classification models for sentiment analysis
- Apply stemming and lemmatization to normalize text data
- Handle real-world text data challenges (noise, slang, special characters)
