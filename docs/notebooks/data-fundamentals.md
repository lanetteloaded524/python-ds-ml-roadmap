# 📊 Data Fundamentals

Master the core Python data stack: NumPy for numerical computing, Pandas for data manipulation, and Matplotlib/Seaborn for visualization. This notebook walks you through real-world data wrangling workflows with hands-on examples.

[![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/djordjeperovic/python-ds-ml-roadmap/blob/main/projects/01_data_fundamentals/data_fundamentals.ipynb)
[![View on GitHub](https://img.shields.io/badge/View-GitHub-blue?logo=github)](https://github.com/djordjeperovic/python-ds-ml-roadmap/blob/main/projects/01_data_fundamentals/data_fundamentals.ipynb)

## Topics Covered

- NumPy array creation, indexing, slicing, and broadcasting
- Vectorized operations and linear algebra with NumPy
- Pandas DataFrames, Series, groupby, merging, and pivot tables
- Handling missing values, duplicates, and data type conversions
- Time series basics with Pandas
- Matplotlib plots (line, bar, scatter, histogram, subplots)
- Seaborn statistical visualizations (heatmaps, pair plots, distribution plots)

## Prerequisites

- Basic Python knowledge (variables, loops, functions, lists, dictionaries)
- Completion of the Math & Statistics notebook (recommended)

## Key Takeaways

- Perform fast numerical computations with NumPy's vectorized operations
- Load, clean, transform, and analyze tabular data with Pandas
- Create publication-quality visualizations with Matplotlib and Seaborn
- Build a complete data wrangling workflow from raw data to insights
- Understand broadcasting rules and avoid common NumPy pitfalls
