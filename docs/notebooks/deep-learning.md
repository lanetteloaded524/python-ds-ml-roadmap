# 🧠 Deep Learning

Dive into neural networks with PyTorch — from tensor basics to training convolutional networks. This notebook is designed for learners transitioning from classical ML to deep learning, with clear explanations of every concept.

[![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/djordjeperovic/python-ds-ml-roadmap/blob/main/projects/03_deep_learning/deep_learning.ipynb)
[![View on GitHub](https://img.shields.io/badge/View-GitHub-blue?logo=github)](https://github.com/djordjeperovic/python-ds-ml-roadmap/blob/main/projects/03_deep_learning/deep_learning.ipynb)

## Topics Covered

- PyTorch tensor creation, operations, and GPU acceleration
- Autograd and automatic differentiation
- Multi-layer perceptrons (MLP) for tabular data
- Activation functions (ReLU, Sigmoid, Softmax)
- Loss functions and optimizers (SGD, Adam)
- Training loops, validation, and early stopping
- Convolutional Neural Networks (CNN) for image tasks

## Prerequisites

- Completion of the ML Fundamentals notebook
- Basic understanding of linear algebra (matrices, dot products)
- Familiarity with the gradient descent concept

## Key Takeaways

- Understand how PyTorch tensors and autograd power neural network training
- Build and train multi-layer perceptrons from scratch
- Implement a complete training loop with validation monitoring
- Understand CNN architectures and when to use them
- Transition confidently from scikit-learn to deep learning frameworks
