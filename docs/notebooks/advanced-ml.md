# ⚡ Advanced ML

Level up with gradient boosting, imbalanced-data techniques, and production-grade pipelines. This notebook covers the tools and techniques used in real-world ML competitions and industry teams.

## Topics Covered

- XGBoost for high-performance gradient boosting
- LightGBM for fast, memory-efficient boosting
- Handling class imbalance with SMOTE (Synthetic Minority Over-sampling Technique)
- End-to-end scikit-learn Pipelines for reproducible workflows
- Advanced feature engineering (interactions, transformations)
- Model comparison and selection strategies
- Production-ready ML code patterns

## Prerequisites

- Completion of the ML Fundamentals notebook
- Understanding of cross-validation and hyperparameter tuning
- Familiarity with scikit-learn's API

## Key Takeaways

- Train and tune XGBoost and LightGBM models for tabular data
- Handle imbalanced datasets using SMOTE and other resampling techniques
- Build reproducible ML workflows with scikit-learn Pipelines
- Compare multiple models systematically and select the best one
- Write production-grade ML code that goes beyond notebooks
