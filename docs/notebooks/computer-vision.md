Apply deep learning to image classification with PyTorch. This notebook guides you through building, training, and evaluating CNNs on synthetic geometric shape data — from image fundamentals to end-to-end model training.

## Topics Covered

- Image fundamentals: tensors, channels, and torchvision transforms
- Convolutional operations: kernels, feature maps, stride, padding
- Pooling layers (max pooling, average pooling)
- Building CNN architectures from scratch
- Data augmentation techniques
- End-to-end CNN training with evaluation and prediction visualization
- Model performance analysis and confusion matrices

## Prerequisites

- Completion of the Deep Learning notebook
- Familiarity with PyTorch tensors and training loops
- Basic understanding of CNNs (convolutions, pooling)

## Key Takeaways

- Understand how images are represented as tensors and processed by CNNs
- Build custom CNN architectures for image classification tasks
- Apply data augmentation to improve model generalization
- Train, evaluate, and visualize CNN predictions on image data
- Debug common issues in computer vision pipelines
