# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| main    | ✅        |

## Reporting a Vulnerability

This is an educational repository — security risks are minimal, but we take all reports seriously.

If you discover a security issue:

1. **Do not** open a public issue
2. Use GitHub's [private security advisory](https://github.com/djordjeperovic/python-ds-ml-roadmap/security/advisories/new) feature
3. Describe the vulnerability and its potential impact
4. We will respond within 48 hours

## Scope

Security concerns most relevant to this repository:
- Dependencies with known vulnerabilities
- Code injection risks in notebooks
- Sensitive data accidentally committed
