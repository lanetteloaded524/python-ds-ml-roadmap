# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] — 2026-03-31

### Added

**Tutorial Notebooks (8):**
- Math & Statistics for ML — distributions, hypothesis testing, Bayes, linear algebra
- Data Fundamentals — NumPy, Pandas, Matplotlib, Seaborn
- EDA Case Study — missing values, outliers, feature engineering
- ML Fundamentals — regression, classification, clustering with scikit-learn
- Deep Learning — PyTorch tensors, MLP, CNN
- Computer Vision — convolutions, feature maps, CNN training
- Advanced ML — XGBoost, LightGBM, SMOTE, Pipelines
- NLP Fundamentals — tokenization, TF-IDF, sentiment analysis

**Exercise Notebooks (5):**
- 22 hands-on exercises with solutions across all major topics

**MLOps Project:**
- FastAPI REST API for model serving
- Dockerfile and docker-compose configuration
- Automated tests with pytest (7 test cases)

**Cheat Sheets (4):**
- NumPy, Pandas, scikit-learn, PyTorch quick-reference guides

**Documentation:**
- Full 10-phase learning roadmap with 27 curated resources
- Portfolio & career guide (resume, interviews, GitHub profile tips)
- Progress tracker for self-paced learning
- MkDocs Material documentation site with 17 pages

**Repository Infrastructure:**
- GitHub Actions CI pipeline (notebook validation + tests + link checking)
- Pre-commit hooks with nbstripout
- Issue templates (bug report, feature request, question)
- Contributing guide, Code of Conduct, Security policy
- Colab badges for all notebooks
